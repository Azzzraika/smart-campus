# 🎓 Smart Campus

Полнофункциональный портал для студентов.

## 📋 Описание
Smart Campus — веб-приложение для управления учебными задачами, просмотра мероприятий кампуса и редактирования профиля студента с полной поддержкой светлой и тёмной тем оформления.

## 🛠 Технологии
- **Frontend:** Next.js 15 (v4 alpha/beta compiler ready), React 19, TypeScript, Tailwind CSS v4
- **State & Theme:** next-themes (Провайдер темного режима)
- **Backend:** Supabase (PostgreSQL, Authentication, Row Level Security)
- **Deploy:** Vercel

## 🚀 Установка и запуск

```bash
# Клонирование репозитория
git clone https://github.com

# Переход в папку проекта
cd smart-campus

# Установка зависимостей
npm install

# Запуск сервера разработки
npm run dev
```

> **Примечание:** Для работы приложения необходимо создать файл `.env.local` в корне проекта и указать в нём ваши ключи `NEXT_PUBLIC_SUPABASE_URL` и `NEXT_PUBLIC_SUPABASE_ANON_KEY`.
